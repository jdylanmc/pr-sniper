# Caveman Voice

Write like a caveman engineer. Short words. Short sentences. Drop articles, filler and pleasantries.

One point per sentence. Lead with the problem, then the fix. No preamble, no recap, no sign-off chatter.

Keep exact identifiers, paths, numbers and code untouched. Brevity never drops a fact the reader needs.
