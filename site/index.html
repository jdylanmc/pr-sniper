> WHAT

Desktop utility. Catch pull requests. Audit with AI. Hand over to human queue.

Configurable. Extensible. Customizable.

Configurable
Schedule per repository. Admission rules pick which pull requests enter.
Extensible
Agents, Doctrines, Voices. Optional Rubber Duck check before post.
Customizable
Permissions per assignment, all off at start. Light, Dark or OS theme.

> INSTALL

  1. Need

    • Apple Silicon Mac.
    • macOS 13.5 or later.
    • Homebrew. No Homebrew? Get at brew.sh.

  2. Install

    One command. Tap repository, install app.

    brew install --cask jdylanmc/pr-sniper/pr-sniper

  3. Launch

    App live in menu bar. No Dock icon.

    open -a "PR Sniper"

  4. First run

    1. Settings › Accounts: connect GitHub account (Git Repository) and Copilot account (AI Tooling). Browser sign-in. No pasted tokens.
    2. Add repository. Pick GitHub account. Pick admission: All or Filtered.
    3. Create Agent (Copilot account and model). Assign to repository. Set Permissions. Mark one assignment Primary.
    4. Enable repository. Watch Queue.

  5. Update

    Quit PR Sniper first. Homebrew own updates. No in-app updater. Settings and credentials stay.

    brew upgrade --cask pr-sniper

  6. Uninstall

    Remove app only. Settings and state stay in ~/Library/Application Support/com.jdylanmc.pr-sniper/. Credentials stay in macOS Keychain. See local data.

    brew uninstall --cask pr-sniper

> NO HOMEBREW

Get signed, notarized ZIP from GitHub Releases. Unzip. Move PR Sniper to Applications. Update by hand.

> WHY

  • Pull request queue grow. Human time not.
  • Agent read diff fast. Agent never bored.
  • Human read only pull requests Agent already vetted.
  • One list for human: Ready for you. Problems go to Needs attention.

> HUMAN KEEP LAST WORD

  • Agent prepare work. Human decide.
  • Nothing post unless permission say so.
  • Never merge without explicit grant.
  • Results stay local.

> HOW

  1. Poll each enabled repository on own schedule.
  2. Admission pick which pull requests enter: All, or ordered Filtered rules (assigned, mentioned, include or exclude users and paths). First enabled match win.
  3. One review per head SHA. New push mean new revision, new review. Same revision: Agent only reply to new comments.
  4. Agent see description, changed files, all comments. Agent act only with explicit permission.
  5. Results land in Queue: Ready for you or Needs attention. Transient failure retry with backoff, 3 attempts, then park. Parked failure auto-resume.
  6. Merged or closed pull request move to Reviewed.

> TERMS

Agent
Copilot account and model, prompt, ordered Doctrines. Assigned per repository.
Voice
Optional writing style for what people read. Ship Caveman, Gilfoyle, Merlin.
Rubber Duck
Optional second Agent. Primary ask before post. Verdict: confirmed, revise, rejected or unverifiable.
Schedule
Per repository: every 5–30 min or 1–4 h, hourly, daily or cron. New repository poll every 30 min.

> SAFETY

  • One review per revision. Publish recheck head SHA before and after.
  • GitHub and Copilot identity separate. Connect one never connect other.
  • Approve and merge: opt-in, primary Agent only, fail closed.
  • Agent get host-owned review tools (reads plus one exit). Boundary, not sandbox.
