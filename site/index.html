> HOW IT WORKS

  1. Poll each enabled repository on its own schedule.
  2. Admission decides which pull requests enter: All, or ordered Filtered rules (assigned, mentioned, include or exclude users and paths). The first enabled matching rule wins.
  3. One review per head SHA. A new push is a new revision and gets another review. On the same revision the Agent only replies to new comments.
  4. Agents see the description, changed files and all comments. They act only with explicit permissions: Publish Comment, Reply Comment, Approve, & Merge. New assignments start with every grant off.
  5. Results land in Queue: Ready for you or Needs attention. Transient failures retry with backoff, 3 attempts, then park. Parked failures auto-resume.
  6. Merged or closed pull requests move to Reviewed. Results stay local.

> TERMS

Agent
A Copilot account and model, a prompt and ordered Doctrines, assigned per repository.
Voice
Optional writing style for what people read. Ships Caveman, Gilfoyle and Merlin.
Rubber Duck
Optional second Agent the primary asks before posting. Verdicts: confirmed, revise, rejected, unverifiable.
Schedule
Per repository: every 5–30 min or 1–4 h, hourly, daily or cron. New repositories poll every 30 minutes.

> SAFETY MODEL

  • Local results. Nothing posts unless a permission says so.
  • One review per revision. Publication revalidates the head SHA before and after.
  • GitHub and Copilot identities are separate. Connecting one never connects the other.
  • Approve and merge are opt-in, primary-Agent-only and fail closed.
  • Agents get host-owned review tools (reads plus one exit). That is a boundary, not a sandbox.

> HOW TO INSTALL

  1. Requirements

    • Apple Silicon Mac.
    • macOS 13.5 or later.
    • Homebrew. Don't have it? See brew.sh.

  2. Install

    One command taps the repository and installs the app.

    brew install --cask jdylanmc/pr-sniper/pr-sniper

  3. Launch

    Open PR Sniper from Applications. It lives in the menu bar, with no Dock icon.

    open -a "PR Sniper"

  4. First run

    Accounts → Repository → Agent → Enable.

    1. Settings › Accounts: connect a GitHub account (Git Repository) and a Copilot account (AI Tooling). Browser sign-in, no pasted tokens.
    2. Add a repository, pick its GitHub account and admission: All or Filtered.
    3. Create an Agent (Copilot account and model), assign it to the repository, set Permissions and mark one assignment Primary.
    4. Enable the repository and watch Queue.

  5. Update

    Quit PR Sniper first. Homebrew owns updates; there is no in-app updater. Settings and credentials are kept.

    brew upgrade --cask pr-sniper

  6. Uninstall

    Removes the app. Settings and state stay in ~/Library/Application Support/com.jdylanmc.pr-sniper/ and credentials stay in the macOS Keychain. See local data.

    brew uninstall --cask pr-sniper

> WITHOUT HOMEBREW

Download the signed, notarized ZIP from GitHub Releases, unzip it and move PR Sniper to Applications. You then update by hand.
